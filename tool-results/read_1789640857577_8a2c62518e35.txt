     1→# Vendly — Whop-style Marketplace & Membership Platform
     2→
     3→## Project Overview
     4→A full digital marketplace + membership platform (Whop clone) built as a **single-page app** at `/` with
     5→client-side view switching. Next.js 16 App Router + TypeScript + Tailwind 4 + shadcn/ui + Prisma (SQLite)
     6→+ Zustand. Payments are simulated server-side across three gateways (Stripe / PayPal / Crypto).
     7→
     8→## Architecture Summary
     9→- **Routing**: user only ever sees `/`. `src/components/app-shell.tsx` switches between view components
    10→  based on `useAppStore().view`: `discover | product | checkout` → `<MarketplaceViews/>`, `portal` → `<PortalViews/>`, `creator` → `<CreatorViews/>`.
    11→- **Session**: demo auth. Client attaches `x-user-id` header via `api()` helper (`src/lib/api.ts`).
    12→  Demo users switchable from the header dropdown. `POST /api/auth/login {email}` creates/finds a user.
    13→- **Simulated clock** ("time machine"): `SystemClock` table. `POST /api/billing/advance {days}` advances
    14→  simulated time and runs the recurring billing engine (renewals, dunning → PAST_DUE → cancel after 3
    15→  failures, trial conversions, cancel_at_period_end). `POST /api/billing/reset` returns to live time.
    16→- **Webhooks**: event-driven access management. Events: subscription.created/renewed/canceled/updated/past_due,
    17→  invoice.paid/payment_failed, license_key.created/revoked, access.granted/revoked. Endpoint providers:
    18→  DISCORD_BOT / TELEGRAM_BOT / GENERIC. Delivery simulated (URL containing "fail"/"500" → FAILED).
    19→- **License keys**: auto-provisioned when product accessType includes LICENSE. Format WHPL-XXXX-XXXX-XXXX,
    20→  max activations, revoke. `POST /api/licenses/validate {key}` = public validation endpoint.
    21→- **Secure delivery**: `POST /api/assets/{id}/link` mints a 10-minute / 3-use token → `GET /api/download/{token}` streams the file.
    22→- **Theme**: emerald accent (NO blue/indigo as primary), light + dark mode via next-themes, rounded-2xl cards.

    33→## API Contract (all JSON; `x-user-id` header required unless marked public)
    34→
    35→### Session
    36→- `GET /api/bootstrap` → `{users: DemoUser[], clock: {simulated, now, label}}` (public)
    37→- `POST /api/auth/login {email}` → SessionUser (public, creates if new)
    38→- `GET /api/me` → SessionUser
    39→- `PATCH /api/me {name?, discordHandle?, telegramHandle?, bio?, role?}` → SessionUser
    40→
    41→### Catalog
    42→- `GET /api/products?q=&category=&sort=featured|members|rating|price&creatorId=` → `{products: ProductCardDTO[]}` (public)
    43→- `GET /api/products/{id}` → `{product: ProductDetailDTO}` (public; hasAccess=true when caller has active sub)
    44→- `POST /api/products {title, tagline?, description, category, accessType: string[], discordRoleName?, telegramChannel?, plans: [{name, description?, priceCents, interval: month|year, trialDays?, badge?, features: string[]}]}` → `{product}` (creator)
    45→- `PATCH /api/products/{id} {title?, tagline?, description?, category?, status?: ACTIVE|PAUSED, featured?, discordRoleName?, telegramChannel?, accessType?: string[]}` → `{product: ProductDetailDTO}`
    46→- `POST /api/products/{id}/reviews {rating: 1-5, comment}` → `{review: ReviewDTO}`
    47→
    48→### Checkout (multi-gateway)
    49→- `POST /api/checkout {planId, gateway: STRIPE|PAYPAL|CRYPTO, startTrial?: bool, card?: {number, expMonth, expYear, cvc}, paypalEmail?, walletAddress?, saveMethod?}`
    50→  - STRIPE/PAYPAL success → `{status: "COMPLETED", subscriptionId, invoiceId, licenseKeyId?, isTrial}` (201). Card ending 0002/9995 declines → 402 `{error}`.
    51→  - CRYPTO → `{status: "PENDING_CRYPTO", subscriptionId, quote: {walletAddress, amountCrypto, asset, network, memo}, plan}` (202)
    52→- `POST /api/checkout/crypto-confirm {subscriptionId}` → `{status: "COMPLETED", subscriptionId, invoiceId, licenseKeyId?, isTrial}`
    53→
    54→### Customer portal
    55→- `GET /api/subscriptions` → `{subscriptions: SubscriptionDTO[]}` (includes plan, product, paymentMethod, invoiceCount, totalPaidCents)
    56→- `PATCH /api/subscriptions/{id} {action}`:
    57→  - `cancel` (at period end) → `{ok, message}`
    58→  - `resume` → `{ok, message}`
    59→  - `cancel_now` → `{ok, message}` (revokes access + licenses)
    60→  - `change_plan {planId}` → `{ok, message}` (proration credit applied)
    61→  - `update_payment {paymentMethodId}` → `{ok, message}`
    62→- `GET /api/invoices?subscriptionId=` → `{invoices: InvoiceDTO[]}`
    63→- `GET /api/payment-methods` → `{paymentMethods: PaymentMethodDTO[]}`
    64→- `POST /api/payment-methods {type: CARD|PAYPAL|CRYPTO, card?, paypalEmail?, walletAddress?, makeDefault?}` → `{paymentMethod}`
    65→- `PATCH /api/payment-methods/{id}` (set default) → `{ok}`; `DELETE /api/payment-methods/{id}` → `{ok}`
    66→- `GET /api/licenses` → `{licenses: LicenseDTO[]}`
    67→- `POST /api/licenses/{id}/activate` → `{ok, activations, maxActivations, device}`
    68→- `DELETE /api/licenses/{id}/activate` → revoke → `{ok}`
    69→- `POST /api/licenses/validate {key}` → `{valid, reason?, product?, plan?, activations, maxActivations}` (public)
    70→- `GET /api/grants` → `{grants: GrantDTO[]}` (Discord/Telegram role sync status)
    71→- `POST /api/assets/{id}/link` → `{url: "/api/download/<token>", expiresIn, maxUses, fileName}` (open url to download)
    72→
    73→### Creator
    74→- `GET /api/analytics` → `{analytics: AnalyticsDTO}` (mrrCents, arrCents, activeSubscriptions, trialingCount, pastDueCount, canceled30d, churnRate, totalRevenueCents, revenue30dCents, avgRevenuePerUserCents, subscriberSeries, revenueSeries, mrrSeries, topProducts, gatewayBreakdown, recentActivity)
    75→- `GET /api/creator/orders` → `{orders: [{id, number, customer, product, planName, description, amountCents, status, gateway, createdAt, paidAt}]}`
    76→- `GET /api/creator/subscribers` → `{subscribers: [{id, customer, product, plan, status, gateway, cancelAtPeriodEnd, dunningAttempts, currentPeriodEnd, trialEndsAt, createdAt, lifetimeValueCents, paymentMethod}]}`
    77→- `GET /api/webhooks/endpoints` → `{endpoints: WebhookEndpointDTO[]}`
    78→- `POST /api/webhooks/endpoints {name, provider: DISCORD_BOT|TELEGRAM_BOT|GENERIC, url, events: string[]}` → `{endpoint}` (201)
    79→- `PATCH /api/webhooks/endpoints/{id} {isActive?, name?, events?}` → `{ok}`; `DELETE …/{id}` → `{ok}`
    80→- `GET /api/webhooks/deliveries?endpointId=&status=&type=` → `{deliveries: WebhookDeliveryDTO[]}` (payload = parsed JSON)
    81→- `POST /api/webhooks/test {eventType, endpointId?}` → `{ok, dispatched}`
    82→- `POST /api/billing/advance {days: 1-90}` → BillingRunResult `{advancedDays, newNow, renewals, renewalsFailed, canceled, trialsConverted, invoicesCreated, events: string[]}`
    83→- `POST /api/billing/reset` → `{ok, message}`
